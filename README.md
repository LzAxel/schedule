# Расписание ФТ23ДР62ПФ

Статический сайт по `schedule.docx`. Для сборки нужен Node.js и одна зависимость для разработки — esbuild. В опубликованный сайт она не попадает.

Сначала установите зависимости:

```sh
npm ci
```

## Локальный запуск

```sh
npm run dev
```

Откройте `http://127.0.0.1:5173`. После правок обновите страницу в браузере. Чтобы изменить порт, задайте `PORT`, например `PORT=3000 npm run dev`.

## Сборка

```sh
npm run build
npm run preview
```

Готовый сайт лежит в `dist/`. Команда `preview` показывает именно собранную версию. При повторной сборке `dist/` пересоздаётся. Папка исключена из Git.

Сборщик объединяет и минифицирует JavaScript, минифицирует CSS и HTML, копирует локальные SVG-иконки и проверяет, что общий размер четырёх файлов в gzip не превышает **14 000 байт**. Внешние шрифты не загружаются. Проверка размера относится к содержимому файлов; сетевые заголовки в неё не входят.

## Как опубликовать

Загрузите исходные файлы в репозиторий GitHub. В **Settings → Pages → Build and deployment** выберите **GitHub Actions**. Workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) будет выполнять `npm ci`, `npm run build` и публиковать только `dist/` при каждом push в `main`.

## Как менять расписание

Откройте [`schedule.js`](schedule.js). Каждая запись в массиве `lessons` — одна пара. `day` — день недели от 1 (понедельник) до 7 (воскресенье), `period` — номер пары. Время пар задано в [`app.js`](app.js), массив `PERIODS`.

Обычная пара проходит каждую неделю:

```js
{ day: 1, period: 4, every: {
  subject: "Название дисциплины", type: "лк",
  teacher: "Преподаватель", room: "303А", building: "К.8, стр.1"
} }
```

Для ячейки, разделённой пополам, задайте `odd` для **верхней** (нечётной) и `even` для **нижней** (чётной) половины. Пустую половину задайте как `null`:

```js
{ day: 2, period: 7,
  odd: { subject: "Название", type: "лб", teacher: "Преподаватель", room: "307В", building: "К.8, стр.3" },
  even: null
}
```

Можно заполнить обе половины разными занятиями. Первая учебная неделя, содержащая `firstEvenWeek: "2026-09-01"`, считается чётной. Чётность переключается каждый понедельник, в том числе при переходе на новый год. Сейчас четыре разделённые пары в документе заполнены сверху и пусты снизу: вторник 7-я, среда 7-я, пятница 7-я, суббота 4-я.

Адрес для `Э*` хранится в поле `buildings`. Если срок обучения изменится, поправьте `semesterStart` и `semesterEnd`.
